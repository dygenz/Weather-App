# 🌦️ Weather App

A responsive weather application built with **HTML, CSS, and JavaScript** that provides real-time weather information, 5-day forecasts, and city search suggestions using public weather APIs.

## 🚀 Live Demo

👉 https://dygenz.github.io/Weather-App/

---

## 📌 Features

- 🌍 Search weather by city
- 📍 Default weather on page load
- 🔍 Smart city search suggestions
- 🌡️ Current temperature and weather conditions
- 📅 5-day weather forecast
- 🌅 Sunrise & sunset timings
- 💧 Humidity
- 🌬️ Wind speed
- 👀 Visibility
- 🌪️ Atmospheric pressure
- 🤗 "Feels Like" temperature
- 🌞 Dynamic weather icons using SVG sprites
- 👋 Time-based greetings (Morning / Afternoon / Evening / Night)
- 🌙 Dark mode toggle
- 📱 Fully responsive design
- ⚡ Keyboard support (Press Enter to search)
- ❌ Error handling for:
  - Invalid city
  - No internet connection
  - Weather API errors
  - Forecast API errors
- 🧠 Optimized API requests using **AbortController** to prevent multiple unnecessary requests while typing
